# Graph Communities

[English](README.md)

Graph Communities 会把 Obsidian 的黑白关系图谱变成一张主题清晰的彩色知识地图。
插件优先按照项目/目录聚类，再结合标题、关键词、标签、别名、标题层级和链接关系增强分类。
每个主要主题拥有不同颜色；关系相近的项目和桥接笔记会呈现相近或自然混合的颜色。

## 主要功能

- 根据知识库目录结构自动识别不同项目。
- 使用标题、路径、标签、别名、标题层级和链接作为本地分类信号。
- 支持 `AI`、`LLM`、`ASR` 或自定义项目名等优先关键词。
- 自动降低 README、index、导航、概览、资源页等通用文件的权重。
- 优先选择有实际主题含义的笔记作为代表节点，而不是导航文件。
- 为不同大型枢纽分配适合深色主题的不同主色。
- 沿邻接关系传播颜色，使关系越紧密的节点颜色越相近。
- 对连接多个社区的桥接节点进行颜色混合。
- 根据两端节点颜色绘制连线，并弱化跨社区连线。
- 同时支持全局图谱和局部图谱。
- 可选图例会显示人类可读的主题/项目名称和节点数量。
- 图谱节点与分类图例会双向联动：打开节点时选中对应分类，点击分类时高亮该分类的全部节点和内部连线。
- 所有计算都在本地完成，不修改笔记内容。

## 视觉规则

```text
蓝色枢纽 ─ 蓝色节点 ─ 蓝紫桥接节点 ─ 紫色节点 ─ 紫色枢纽
```

节点大小仍由 Obsidian 控制，插件只改变颜色：

- **主色**：表示所属知识社区。
- **颜色相似度**：表示图关系的相似程度。
- **混合色**：表示连接多个社区的边界节点。
- **柔和中性色**：表示孤立或暂时无法分类的笔记。

## 交互式聚焦

- 悬停图谱节点时，图例会立即预览并标记对应分类；点击节点并打开笔记后，该分类会保持选中状态，节点也会进一步突出。
- 点击图例中的分类，会高亮该分类下的全部节点及内部连线，并弱化无关节点和连线。
- 再次点击当前分类，或运行 **Graph Communities: Clear graph community focus**，即可恢复完整图谱。
- 当前选中的笔记名称会显示在分类图例上方。

## 安装方式

### 从 Release 手动安装

1. 从最新 Release 下载 `main.js`、`manifest.json` 和 `styles.css`。
2. 新建 `<知识库>/.obsidian/plugins/graph-communities/` 文件夹。
3. 将三个文件复制到该目录。
4. 重启 Obsidian。
5. 进入 **设置 → 第三方插件**，启用 **Graph Communities**。

### 本地开发安装

项目除了 Node.js 外没有其他构建或运行依赖：

```bash
npm run verify
node scripts/install-local.mjs /path/to/vault --enable
```

安装新构建后需要重启或重新加载 Obsidian。

## 推荐初始设置

| 设置 | 默认值 | 作用 |
| --- | ---: | --- |
| 最大社区数量 | 12 | 限制主要主题/项目颜色数量 |
| 最小社区规模 | 3 | 合并小碎片或将其显示为中性色 |
| 主题感知聚类 | 开启 | 综合项目、关键词、元数据与链接 |
| 优先主题关键词 | AI, LLM, ASR, RAG, Agent | 强化指定主题的聚类与命名 |
| 项目/目录影响 | 5.0 | 让同一项目中的笔记保持聚集 |
| 关键词相似度影响 | 1.4 | 让本地元数据相似的笔记更接近 |
| 聚类分辨率 | 1.0 | 越低社区越少越大，越高社区越多越细 |
| 关系混合强度 | 0.52 | 越高，跨链接的颜色混合越明显 |
| 混合距离 | 4 | 颜色沿多少层链接传播 |
| 弱化外围节点 | 0.18 | 让大型枢纽更加突出 |

大量调整链接后，可以运行命令：
**Graph Communities: Recompute graph communities**。
插件也会在元数据索引完成或 Markdown 文件变化后自动重新计算。

## 算法原理

1. 从有意义的目录名识别项目边界，尽量跳过 `docs`、`src`、`references`、`archive` 等结构目录。
2. 从文件名、路径、标签、别名和标题层级生成本地关键词向量。
3. 综合项目关系、关键词相似度和降权后的内部链接构建图谱。
4. 默认让每个主要项目形成一个基础社区；非项目优先模式仍可使用确定性 Louvain 聚类。
5. 对 README、index 等导航文件施加强降权，选择更有主题含义的代表笔记。
6. 在指定的链接层数内传播社区亲和度向量。
7. 根据每个节点的社区亲和度在线性 RGB 空间混合颜色，形成自然过渡色。

该模型只使用本地元数据，不读取正文段落，不调用云端嵌入模型，也不会上传知识库内容。

## 隐私与安全

- 全部计算在 Obsidian 本地完成。
- 不发送网络请求，不收集分析数据，不需要 API Key。
- 不创建、修改、移动或删除笔记。
- 插件设置使用 Obsidian 标准插件数据机制保存。
- 禁用或卸载插件后，会恢复主题原本的节点颜色。

## 兼容性说明

Obsidian 暂未通过公开插件 API 提供逐节点着色能力，因此本插件与其他图谱着色插件一样，
需要访问图谱渲染器的内部节点和连线对象。未来 Obsidian 升级后可能暂时需要兼容更新；
即使出现兼容问题，也只会导致颜色不显示，不会影响知识库内容。
